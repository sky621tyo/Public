# 三段表メーカー

法律・政令・省令（規則）の条文を横に並べて、三段表をつくるツールです。HTMLファイル1つで動き、インストールは要りません。

## できること

- **e-Govから取得**：法律名を入れると、その施行令と施行規則を自動で選び、[e-Gov法令API（v2）](https://laws.e-gov.go.jp/)から現行の条文を取得して三段表にします。
- **条文を貼り付け**：e-Gov法令検索などからコピーした条文を貼り付けても、三段表をつくれます。
- **自動の対応付け**：政令・省令の中の「法第〇条」「令第〇条」「前条」を読み取り、上位の法令の条と同じ行に並べます。「政令で定める」などの委任の文言は色付きで強調します。
- **Word・Excelへのコピー**：罫線付きの表のまま貼り付けられます。ブラウザの印刷機能（Ctrl+P）を使えば、A4横向きで印刷できます。

## 使い方

1. `index.html` を開き、右上の「Download raw file」で保存して、Chrome や Edge で開きます。
2. 「e-Govから取得」タブで法律名を入れ、「探して三段表をつくる」を押します。
3. 並びがずれている行は「表を直接編集」で直してから、コピーまたは印刷します。

## 注意

- 対応付けは、条文中の引用の書き方をもとにした機械的な推定です。「法」「令」という略称を定義していない法令や、他の法律を引用している条では、並びがずれることがあります。実務で使うときは、必ず原文と照らし合わせてください。
- 条文データは e-Gov法令検索（デジタル庁）から取得しています。
